# sync-core

Прочитай docs/vision.md и сценарий этапа. Проследи путь индексирование → версия → передача → подтверждение. Проверь сохранение архивной копии при удалении источника, устойчивость повторной передачи и фиксацию результата после проверки хеша. Для изменения политики проверь независимые офлайн-правки и конфликт удаления с правкой. В отчёте укажи точки входа и границы записи состояния.

Следуй правилам передачи результатов и ведения журнала в AGENTS.md.
